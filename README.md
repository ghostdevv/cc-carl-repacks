# cc-carl-repacks

Repackaged packages for [cc-carl](https://github.com/ghostdevv/cc-carl).

```bash
carl repo add https://raw.githubusercontent.com/ghostdevv/cc-carl-repacks/refs/heads/main/carl-repo.json
```

## ComBox

> An all-in-one rendering system for CC:Tweaked. All about render quality and customizability

https://github.com/hexelll/ComBox

> [!NOTE]
> Until lifecycle hooks are added or [ComBox adds a license](https://github.com/hexelll/ComBox/issues/7) you can only have one version of combox installed, and you must create a file called `/.combox_secrets` with the content `/.carl/packages/combox/`
